# どこの裁判所？（saibansho-doko）

お金の訴え・少額訴訟・遺産分割や離婚などの家庭の事件・少年の事件・罰金の罪・控訴などの場面を読んで、その事件を扱う裁判所（簡易・家庭・地方・高等・最高）を当てる1日5問の学習ゲーム。正解したら、その裁判所の判断に不服を言うと次はどこか（地方裁判所／高等裁判所／最高裁判所／同じ簡易裁判所へ異議）も選ぶ。裁判所のしくみ（三審制）の学習に。

遊ぶ: <https://satou-aaaaa.github.io/saibansho-doko/>

- 中身は e-Gov 法令検索の裁判所法（<https://laws.e-gov.go.jp/law/322AC0000000059>）第7・16・24・31条の3・33条、民事訴訟法（<https://laws.e-gov.go.jp/law/408AC0000000109>）第311・368・377・378条、家事事件手続法（<https://laws.e-gov.go.jp/law/423AC0000000052>）第117・123・150・156・191・198・201・257条に書いてあることだけです（2026-11-26 に読んだ今の条文）。
- 説明は条文を、短く言いかえたものです。管轄の合意（民事訴訟法 第11条）・移送・不動産の訴え・どの町の裁判所か・裁判所規則・費用は省いています。公式の情報の代わりではありません。実際の手続きは、裁判所の案内や専門家に確かめてください。
- 2段目は、その裁判所の判断（判決・審判・決定）に不服を言ったときの行き先です。
